# Calculator Application

A simple and elegant calculator built with HTML, CSS, and JavaScript that provides basic arithmetic operations with a clean user interface.

## Getting Started

Simply open the `cal.html` file in a web browser to start using the calculator.

## Features

- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-) 
  - Multiplication (*)
  - Division (/)
- Decimal point support
- Real-time calculation display
- Responsive design with styled buttons
- Beautiful UI with background image

## Technologies Used

- HTML5
- CSS3 
- JavaScript (Vanilla)

## Usage

1. Click number buttons to input values
2. Select an operation (+, -, *, /)
3. Enter second number
4. Press = to see the result
5. Use C button to clear and start over

## UI Components

- Display screen showing:
  - Current input
  - Calculation result
- Numeric keypad (0-9)
- Operation buttons
- Clear button (C)
- Equals button (=)
- Decimal point button (.)

## Project Structure

- `cal.html` - Main HTML structure
- `cal.css` - Styling and layout
- `cal.js` - Calculator logic and functionality
