## 🌟 Why This Repository Exists

This project is designed specifically for anyone taking their first steps into the world of open source. It allows developers of all levels to:

- 🔀 **Practice Fundamental Git**: Get comfortable with the most used `fork`, `clone`, `branch`, `commit`, `push`, and `pull-request` workflow.
- 🤝 **Learn Collaboration**: Experience the entire process of collaborative codings, from issue discussion to code review.
- 🏅 **Publicly Showcase Work**: Share and showcase small coding projects publicly on GitHub.
- 🚀 **Earn a "Merged" PR**: Get that satisfying feeling of having your first contribution merged into a real project.
