## Run a Project Locally

This repository contains multiple mini projects.  
To run any project:

1. Open the project folder you want to run:
```bash
cd <project-folder-name>


✅ For React/Vite projects:
```bash
npm install
npm run dev

For React(CRA) projects:
npm install
npm start

For Node.js projects:
npm install
node index.js


For simple HTML/CSS/JS projects:  
Just open the `index.html` file in your browser.
