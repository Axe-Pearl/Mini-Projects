# Mini Projects

A collection of simple and beginner-friendly mini projects. These projects are useful for learning programming concepts and practicing development skills.

## Projects

### Calculator

A simple calculator project for performing basic arithmetic operations.

### Clock

A simple clock application that displays the current time.

### Password Generator

Generates secure random passwords.

### Temperature Converter

Converts temperatures between different units such as Celsius and Fahrenheit.

### Text Utilities

A collection of useful text-processing operations.

### TODO List

A simple TODO list application for adding and managing tasks.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Axe-Pearl/Mini-Projects.git
```

### Open the Project

```bash
cd Mini-Projects
```

Choose any project folder and follow the instructions provided in its respective `README.md` file.
